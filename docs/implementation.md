# Реализация React Observatory
План утверждён пользователем в чате 16.10.2026.
1. Контракты, компилятор, sandbox и тесты.
2. Восемь лабораторий с проверками поведения.
3. Интерфейс: обзор, лаборатория, разбор, практика, видео, библиотека.
4. Экспорт, статическое демо, реальные видео и комплект портфолио.
5. Браузерные проверки, финальное ревью и исправления.

Решения: отдельный новый Git-репозиторий выполняет требование изоляции. Sandbox — development React в отдельном IIFE; основной интерфейс — production React. Публикация: подготовить статическую сборку и использовать Sites для публичного демо, если доступен сервис. Произвольный код экспортируется только как данные записи, никогда не запускается сервером.

Дизайн: #f7f8fa canvas, #ffffff surfaces, #182336 ink, #2955e8 cobalt, #6c52bd effect, #0d886e commit. Onest для интерфейса, JetBrains Mono для кода. Слева узкая навигация, в центре большое поле эксперимента; схемы задают характер продукта.

## Завершённые этапы

- Ядро, 8 лабораторий, интерфейс и локальная очередь реализованы.
- Записаны 16 реальных браузерных экспериментов; исходные и исправленные записи проверены отдельно.
- Финальное независимое ревью: все 6 значимых замечаний устранены через воспроизводящие тесты.
- Исправления: согласованный сценарий видео; последний ввод задачи; восстановление job ID; независимость черновика от просмотра записи; согласованные лимиты JSON; проверка перехода +3 за одно действие.
- До исправлений тесты воспроизвели дефекты; после исправлений — 15 unit и 17 E2E прошли. Дополнительно добавлена проверка всех пар готовых записей (итоговый прогон ниже).
