# Проверки перед поставкой

Проверено 16 октября 2026 года на macOS Apple Silicon, Node.js 24.

## Автоматические проверки

- `npm test`: 16 тестов проходят. Контракты записей, порядок событий, отбрасывание старых сообщений, компиляция TSX, ограничения импортов, ограничение циклов, source-line метки, границы видеосцен, сценарии для исправленного кода, восемь пар записей, поведение batching/keys и HTTP-очередь со скачиванием.
- `npm run test:e2e`: 17 сценариев проходят в Google Chrome. Во всех лабораториях проверены исходный и исправленный варианты через реальные взаимодействия в iframe.
- Отдельно проверены сохранение и перезагрузка, перенос JSON, ошибки TSX и runtime, восстановление среды, development Strict Mode, собственный TSX, просмотр видео, экспорт сценария/SRT, потеря доступа к job при закрытии вкладки, сохранность нового черновика и импорт записи больше 2 МБ.
- Адаптивность проверена на ширине 390, 768 и 1440 px; горизонтального переполнения нет. Есть отдельные мобильный и настольные скриншоты.
- `npm run build:demo` выполняет TypeScript и production-сборку. Тяжёлый компилятор выделен в Worker.
- `npm run format:check` проверяет форматирование исходников и тестов.

## Полный реальный экспорт

`scripts/verify-local-render.ts` отправил запрос на настоящий Express API, дождался завершения Remotion, скачал файл по HTTP и проверил его метаданные. Получен 1920×1080, H.264, 30 fps. Результат — `http-render-verification.json`.

Все девять готовых MP4 проверены через `getVideoMetadata`: восемь уроков по 48 секунд и обзор продукта 60 секунд. Погрешность контейнерной длительности менее 0.1 секунды. Результаты — `video-metadata.json`.

Видеокадры дополнительно просмотрены визуально: исходный код, типографика, схема, контрольная запись исправления и демонстрация продукта.

## Статическое демо и браузеры

Статическая сборка проверена через отдельный Vite preview. В Chrome и WebKit работают переходы по hash-ссылкам, обновление страницы, TSX-исполнение, отключение серверного рендера в режиме демо, загрузка MP4 и перемотка. Ошибок JavaScript в этих сценариях не зарегистрировано. WebKit проверен автоматизированно на macOS; это не тест на физическом iPhone.

Требуемая версия Firefox отсутствует, поэтому проверка в Firefox не заявляется. Подробности — `browser-verification.json`.

## Независимое ревью

Проведено отдельным агентом, без изменения им исходников. Все шесть существенных замечаний исправлены и покрыты воспроизводящими проверками:

1. Текст видео соответствует исходному или исправленному варианту.
2. Проверка ключей использует последнее введённое значение.
3. Последний экспорт восстанавливается после закрытия видеовкладки.
4. Просмотр сохранённой записи не заменяет более новый черновик.
5. Размер переносимой записи согласован между импортом и экспортом.
6. Три обычных клика не проходят проверку одного изменения на +3.

Дополнительная реальная интеграционная проверка выявила ограничение Express на скрытую папку `.renders`. Выдача разрешена только для известного завершённого задания; отдельный тест проверяет HTTP 200 и содержимое скачанного файла.
